Match decode options to how the message was encoded. Wrong flags will produce incorrect output.
—
Standard : Letters ←1 on row · spaces/punctuation unchanged
Edge wrap : Q→P · A→L · Z→M (far-left wraps to far-right)
Numbers ON : Digits in text ←1 (1→0 … 0→9)
Number row : Then top-row letters → Q=1 W=2 E=3 … P=0
Mixed ON : Count letters/digits only — odd ←1 · even ←2
Double ON : After pass 1, whole message ←1 again (letters + digits)
Reverse ON : Flip final string (decode: un-reverse first)
Decode : un-reverse → 1-0→letters → undo double → undo main
Example : ADD → LSS  ·  A1 (all on) → 8K

about

Each letter shifts left on its QWERTY row (edge keys wrap). Numbers mode also shifts digits ←1 on 1–0, then converts top-row letters to digits (Q=1 … P=0). Mixed alternates ←1 / ←2. Double adds a second ←1 pass; Reverse flips the final string.
