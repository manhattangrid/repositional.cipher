Encode rule : Every letter → left neighbor on its row
Edge wrap : Far-left keys wrap to far-right of the same row
Wrap keys : Q→P  ·  A→L  ·  Z→M
Top row : Q→P, W→Q, E→W, R→E … P→O
Home row : A→L, S→A, D→S, F→D … L→K
Bottom row : Z→M, X→Z, C→X, V→C … M→N
Decode : Shift right on each row (P→Q, L→A, M→Z at edges)
Example : ADD → LSS (A wraps to L; D→S; D→S)
Mixed mode : Odd letters shift right (with wrap) instead
Number row : After encode: Q=1 W=2 E=3 … P=0
Extras : Reverse · Double encode

about

The Repositional Cipher shifts each letter to its left neighbor on the QWERTY row. Keys on the far left (Q, A, Z) wrap to the far right of that row. Decode by shifting right. Fully reversible — no collisions. Optional mixed, number row, reverse, and double-encode modes.
